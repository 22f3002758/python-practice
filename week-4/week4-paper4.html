Question 3MCQ
3 marks · no negative marks

random.random() returns a random float from 0 (included) to 1 (excluded). Consider the below code. Which value is the printed number closest to?

Python
import random
inside = 0
n = 20000
for i in range(n):
    x = random.random()
    y = random.random()
    if x * x + y * y <= 1:
        inside += 1
print(4 * inside / n)

Choose one option

View answer and solution

Correct answer: C — 3.14

The point (x, y) is uniform in the unit square, and x * x + y * y <= 1 holds inside the quarter circle of radius 1, whose area is pi / 4. So inside / n is close to 0.785, and multiplying by 4 estimates pi.

Question 4MCQ

Given the following code snippet, what will be the output?

Python
L = [2, 1, 3, 5, 4]
passes = 0
swapped = True
while swapped:
    swapped = False
    passes += 1
    for i in range(len(L) - 1):
        if L[i] > L[i + 1]:
            t = L[i]
            L[i] = L[i + 1]
            L[i + 1] = t
            swapped = True
print(L, passes)

Choose one option

View answer and solution

Correct answer: A — [1, 2, 3, 4, 5] 2

The first pass swaps 2 with 1 and 5 with 4, which already sorts the list, and sets swapped. The second pass makes no swaps, so swapped stays False and the loop ends. The pass that finds nothing to swap still counts.

Output
[1, 2, 3, 4, 5] 2

Snippet-2
