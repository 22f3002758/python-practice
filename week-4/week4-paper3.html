Question 4MCQ

Given the following code snippet, what will be the output?

Python
L = [7, 4, 9, 2, 5]
for i in range(1, 4):
    j = i
    while j > 0 and L[j - 1] > L[j]:
        t = L[j]
        L[j] = L[j - 1]
        L[j - 1] = t
        j -= 1
print(L)

Choose one option

View answer and solution

Correct answer: A — [2, 4, 7, 9, 5]

Insertion sort moves L[i] left while its left neighbour is larger. For i = 1, 4 moves before 7. For i = 2, 9 is already in place. For i = 3, 2 moves to the front. The loop stops at i = 3, so 5 is not placed.

Output
[2, 4, 7, 9, 5]

    for i in range(2):
        for j in range(2):
            for k in range(2):

    P = R

Enter a number

View answer and solution

Correct answer: 6

P starts as the identity matrix and is multiplied by A three times, so it ends as A cubed. A squared is [[1, 4], [0, 1]] and A cubed is [[1, 6], [0, 1]]; each multiplication adds 2 to the top-right entry.
