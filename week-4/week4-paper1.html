Question 3MCQ
3 marks · no negative marks

Consider the below code. Which statement best describes the printed value?

Python
import random
hits = 0
trials = 10000
for t in range(trials):
    a = random.randint(1, 6)
    b = random.randint(1, 6)
    if a + b == 7:
        hits += 1
print(hits / trials)

Choose one option

View answer and solution

Correct answer: D — About 0.17, because 6 of the 36 equally likely pairs add up to 7

hits / trials is the fraction of trials in which the two rolls add up to 7, so it estimates that probability. The pairs (1, 6), (2, 5), (3, 4), (4, 3), (5, 2) and (6, 1) are 6 of the 36 equally likely outcomes, and 6 / 36 is about 0.17. The 11 sums are not equally likely, and dividing by trials turns the count into a fraction.

L = [5, 2, 9, 1, 7]
for i in range(len(L) - 1):

        L[i] = L[i + 1]
        L[i + 1] = t
print(L)

Choose one option

View answer and solution

Correct answer: A — [2, 5, 1, 7, 9]

One pass compares each neighbouring pair from left to right and swaps it when the left value is larger. 5 and 2 swap, 5 and 9 stay, 9 and 1 swap, then 9 and 7 swap. The largest value ends at the end, but one pass does not sort the rest.

        floor = f

Correct answer: A — [0, 3, 1, 4, 0] 12

The second 3 is the current floor, so it is skipped. The lift moves 3, 2, 3 and 4 floors, which is 12, and each new floor is appended after the starting floor 0.
