import random
flips = []
for i in range(1000):
    flips.append(random.choice(['H', 'T']))
n = 0
for i in range(1, len(flips)):
    if flips[i] == flips[i - 1]:
        n += 1
print(n)

Choose one option

View answer and solution

Correct answer: C — About 500, because each of the 999 neighbouring pairs matches with probability 1/2

random.choice picks H or T with equal chance. n counts the neighbouring pairs (999 of them) whose two flips match, and a pair is HH or TT with probability 1/4 + 1/4 = 1/2. The value changes from run to run, but stays near 500.

Each pass of selection sort finds the smallest value from index i onwards and swaps it into index i. Pass 0 swaps 1 with 6, giving [1, 3, 8, 6, 5]. In pass 1 the smallest value from index 1 is 3, already in place. The outer loop runs only twice, so the rest is not sorted.

Python
S = 0
for x in L:

c = 0
for x in L:

        c += 1

Choose one or more options

View answer and solution

Correct answer: A, B and D

S is the sum, so x * len(L) > S means x > S / len(L), the average. Not every element can be above the average, so c < len(L). If all elements are equal, none is above the average and c is 0; otherwise the largest element is above it, so c is 0 exactly when all are equal.

Questions 16 and 17 are based on the following code, which simulates a queue. What is printed when the input is a !b c !!d?

Python
q = input().split()
served = []
while len(q) > 0:
    p = q.pop(0)
    if p[0] == '!':
        q.append(p[1:])
    else:
        served.append(p)
print(served)

Choose one option

View answer and solution

Correct answer: A — ['a', 'c', 'b', 'd']

A name starting with ! loses one ! and goes to the back of the queue. a and c are served first, !b returns as b, and !!d returns as !d, then again as d.

Output
['a', 'c', 'b', 'd']
