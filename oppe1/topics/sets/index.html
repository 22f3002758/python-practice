Core problems

9 problems

The data structure is central to each of these tasks.

Problem 1

Core

More Than Five Unique Digits

Given an integer, return True if it contains more than five distinct digits; otherwise return False.

Problem 2

Core

Unique Characters in the First Word Only

Given two lowercase words, return the set of unique characters present in the first word but absent from the second.

Problem 3

Core

Count Unique Common Digits

Given two integers, return the number of distinct digits appearing in both.

Problem 4

Core

Number with More Unique Digits

Given two positive integers, return the one with more distinct digits. If they have the same number, return tuple (n1, n2).

Problem 5

Core

Cartesian Points Processing

Given a set of coordinate tuples and a requested operation, sort by absolute x-coordinate with polar-angle tie-breaking; find the point closest to the origin by Manhattan distance with polar-angle tie-breaking; or group points by quadrant into a dictionary mapping each non-empty quadrant to a set of points.

Problem 6

Core

Count Unique Even and Odd Numbers

Given a list of integers, count distinct even and odd numbers and return a dictionary with keys even and odd.

Worked slides: 2025_Jan_oppe1_set1 · S2·P1 →

Problem 7

Core

Student Score Filter

Given a dictionary mapping student names to score lists, return the set of names meeting a requested condition: excellent (average at least 85), good (average at least 50 and below 85), all_pass (every score at least 50), or balanced (max minus min at most 10).

Worked slides: 2025_Jan_oppe1_set1 · S3·P1 →

Problem 8

Core

Find the Missing Number in a Range

Given a list of integers and n, find the number in the range 1 through n that does not appear. The supplied example includes duplicates, so the example permits duplicate entries.

Worked slides: 2025_Jan_oppe1_set2 · S1·P3 →

Problem 9

Core

Merge Two Lists and Remove Duplicates

Implement merge_and_remove_duplicates(list1, list2) and return a set containing all unique elements from both lists.

Related problem R1

Optional

Analyze Sentences

Implement process_sentence(sentence, task) to count words, count palindrome words, count words containing repeated characters, or return a set of all longest words. Sets support unique-character checks and are explicitly required for the longest-words result. Preserve the portal's expected task identifier where it differs from the descriptive task name.

Check for Vowels at Even Indices

Return True if no vowel occurs at an even index, otherwise False. A set of vowels is a common, natural membership-check approach while iterating over even indices.
