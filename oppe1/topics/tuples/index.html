Core problems

10 problems

The data structure is central to each of these tasks.

Problem 1

Core

Final Position

Given initial position tuple (x, y), velocity tuple (vx, vy), and time, calculate the final position.

Problem 2

Core

Repeat Tuple Elements

Given tuple (a, b), return a tuple containing a repeated b times, followed by b repeated a times.

Problem 3

Core

Manhattan Distance via an Intermediate Point

Given coordinate tuples a, b, and c, calculate Manhattan distance from a to b plus distance from b to c.

Problem 4

Core

Student Marks Filter

Given tuples (roll_number, marks) and a criterion, filter while preserving input order: above_average means marks at least the average; below_average means below average; fail means below 40; toppers means at least 90; no criterion returns all; invalid criterion returns None.

Worked slides: 2024_Sep_oppe1_set1 · S3·P1 →

Problem 5

Core

Replace the Middle Element with N Copies

Given an odd-length tuple and integer n, replace the middle element with n copies of that element and return the tuple.

Worked slides: 2024_Sep_oppe1_set2 · S1·P3 →

Problem 6

Core

Check if 2D Vectors Are Orthogonal

Implement are_orthogonal(t1, t2). Return True if the dot product x1*x2 + y1*y2 is zero; otherwise return False.

Problem 7

Core

Key Stroke Analysis

Given events as tuples (key, press_time, release_time), calculate average hold time for a key, average transition time between two keys, final typed text with backspaces applied, and words per minute. Events are ordered and timings do not overlap.

Problem 8

Core

Rearrange Even-Length Tuple by Placing Middle Elements at Ends

For an even-length tuple, move its first middle element to the beginning and its second middle element to the end, preserving the order of all remaining elements.

Problem 9

Core

Railway Ticket Booking Analysis

Passenger records are tuples (passenger_name, berth_preference). Analyze ticket prices, revenue, berth-preference counts (including zero counts and None), and passenger counts by coach type. Also listed under Dictionary — Direct.

Problem 10

Core

Shuffle a Three-Word Sentence

Given a sentence of exactly three words and a tuple of three zero-based indices, return the words in the order specified by the tuple.

Cross-listed problem: Railway Ticket Booking Analysis is also in Dictionary — Direct because bookings are nested dictionaries.
