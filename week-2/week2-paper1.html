Question 1MCQ
3 marks · no negative marks

Consider the below code snippet. The user enters 30. What will be the output?

Python
temp = int(input())
alert = False
if temp > 35:
    alert = True
    if temp > 40:
        msg = "Severe heat"
    else:
        msg = "Heat"
elif temp > 25:
    if temp > 30 or alert:
        msg = "Warm"
    else:
        msg = "Pleasant"
else:
    msg = "Cool"
print(msg)

Choose one option

View answer and solution

Correct answer: A — Pleasant

30 is not greater than 35, so the first block is skipped and alert stays False. 30 is greater than 25, so the elif block runs. Inside it, temp > 30 is False and alert is False, so the inner else sets msg to "Pleasant".

Output
Pleasant

Correct answer: B — 3 x 49.50 = 00148.50

Question 7MCQ
3 marks · no negative marks

A shop gives a 20% discount on bills of 5000 or more, 10% on bills of 2000 or more, and nothing otherwise. Each snippet reads the bill amount and should print the discount percentage. Choose the correct option.

Snippet-1

Snippet-1
amt = int(input())
if amt >= 2000:
    d = 10
elif amt >= 5000:
    d = 20
else:
    d = 0
print(d)

Snippet-2

Snippet-2
amt = int(input())
d = 0
if amt >= 5000:
    d = 20
if amt >= 2000:
    d = 10
print(d)

Choose one option

View answer and solution

Correct answer: C — Both snippets are incorrect

In Snippet-1 the condition amt >= 2000 is checked first, so a bill of 8000 stops there and gets 10; the elif amt >= 5000 branch can never run. In Snippet-2 both if statements are independent: for 8000, d becomes 20 and is then overwritten with 10. The larger threshold must be tested first in an if-elif chain.

Question 13NAT

What number is printed by the following code?

Python
s = "banana bandana"
print(s.count("an") + s.find("d") - s.index("b", 1))

Enter a number

View answer and solution

Correct answer: 7

count("an") finds two non-overlapping matches in each word, 4 in total. find("d") gives the index of the only d, which is 10. index("b", 1) starts searching at index 1, so it skips the first b and returns 7. 4 + 10 - 7 = 7.

Output
7
