Question 1MCQ
3 marks · no negative marks

Consider the below code snippet. The user enters 250. What will be the output?

Python
units = int(input())
if units <= 100:
    rate = 3
elif units <= 200:
    rate = 5
elif units <= 300:
    rate = 7
else:
    rate = 9
if units > 150 and rate < 7:
    rate = rate + 1
print(units * rate)

Choose one option

View answer and solution

Correct answer: A — 1750

250 is not at most 100 or 200 but is at most 300, so rate is 7. The second if needs both units > 150 and rate < 7; the second part is False, so the rate stays 7. 250 × 7 = 1750.

Output
1750

A year is a leap year if it is divisible by 400, or divisible by 4 but not by 100. Each snippet reads a year and should print Leap or Not leap. Choose the correct option.

Snippet-1

Snippet-1
y = int(input())
if y % 400 == 0:
    print("Leap")
elif y % 100 == 0:
    print("Not leap")
elif y % 4 == 0:
    print("Leap")
else:
    print("Not leap")

Snippet-2

Snippet-2
y = int(input())
if y % 4 == 0 and y % 100 != 0 or y % 400 == 0:
    print("Leap")
else:
    print("Not leap")

Choose one option

View answer and solution

Correct answer: B — Both snippets are correct

Snippet-1 tests the most specific rule first: 400 means leap, otherwise 100 means not leap, otherwise 4 means leap. Snippet-2 combines the rules in one condition. and binds tighter than or, so it reads (divisible by 4 and not by 100) or divisible by 400, which is exactly the definition.
