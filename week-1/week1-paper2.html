Correct answer: B — True False

Consider the below code snippet. What happens when it is executed?

Python
print(int("4.5") + 1)

Choose one option

View answer and solution

Correct answer: B — It raises a ValueError

int() can convert a string only if it looks like a whole number. "4.5" has the right type (a string) but an unsuitable value, so a ValueError is raised. int(float("4.5")) would work and give 4.

Output
