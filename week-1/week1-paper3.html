Question 2MCQ
3 marks · no negative marks

Given the following code snippet, what will be the output?

Python
print(2 ** 3 ** 2 % 10, (2 ** 3) ** 2 % 10)

Choose one option

View answer and solution

Correct answer: A — 2 4

** groups from the right, so 2 ** 3 ** 2 is 2 ** 9, which is 512, and 512 % 10 is 2. With explicit parentheses (2 ** 3) ** 2 is 64, and 64 % 10 is 4. ** is applied before % in both.

Output
2 4

Question 7MCQ

Given the following code snippet, what will be the output?

Python
print("apple" < "banana", "Zebra" < "apple", "10" < "9")

Choose one option

View answer and solution

Correct answer: A — True True True

Strings are compared character by character. "a" comes before "b". Every uppercase letter comes before every lowercase letter, so "Zebra" < "apple". "10" < "9" compares the characters "1" and "9", not the numbers 10 and 9.

Output
True True True
Question 8MCQ

Consider the below code snippet. What happens when it is executed?

Python
s = "hello"
s[0] = "J"
print(s)

Choose one option

View answer and solution

Correct answer: D — It raises a TypeError

Strings are immutable: a character cannot be replaced by assigning to an index, and attempting it raises a TypeError. A new string must be built instead, for example "J" + s[1:].

Output
TypeError: 'str' object does not support item assignment
