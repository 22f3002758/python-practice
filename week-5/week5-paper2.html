Given the following code snippet, what will be the output?

Python
def scale(L, k=2):
    out = []
    for x in L:
        out.append(x * k)
    return out

def shift(L, k):
    return scale(L, 1)[k:] + scale(L)[:k]

print(shift([1, 2, 3], 1))

Choose one option

View answer and solution

Correct answer: A — [2, 3, 2]

scale(L, 1) copies the list, so [1:] is [2, 3]. scale(L) uses the default k = 2, giving [2, 4, 6], and [:1] is [2].

Output
[2, 3, 2]
Question 2MCQ
3 marks · no negative marks

Select the correct implementation of a function gcd(a, b) that returns the greatest common divisor of two positive integers.

Choose one option

View answer and solution

Correct answer: D

Euclid's rule replaces (a, b) by (b, a % b) until the remainder is 0; the other number is then the gcd. Returning b at that point always returns 0. Counting up from 1 returns the smallest common divisor, which is always 1. The loop overwrites a before using it, so b becomes b % b, which is 0.

Question 8MCQ
3 marks · no negative marks

Both snippets define digsum(n), which should return the sum of the digits of a non-negative integer n. Choose the correct option.

Snippet-1

Snippet-1
def digsum(n):
    if n < 10:
        return n
    return n % 10 + digsum(n // 10)

Snippet-2

Snippet-2
def digsum(n):
    if n == 0:
        return 0
    return n // 10 + digsum(n % 10)

Choose one option

View answer and solution

Correct answer: A — Only Snippet-1 is correct

Snippet-1 adds the last digit n % 10 to the digit sum of the rest, n // 10. Snippet-2 swaps the two: it adds the rest as a number and recurses on the last digit. A single digit such as 3 then calls digsum(3) again forever, which raises RecursionError.

Select all correct implementations of a function three(L) that returns True if the list L has the same value three times in a row, and False otherwise. For example, three([1, 2, 2, 2]) is True and three([4, 4, 1, 4, 4]) is False.

Choose one or more options

View answer and solution

Correct answer: A and D

The run length must go back to 1 whenever a value differs from the one before it. Without that reset, the two pairs in [4, 4, 1, 4, 4] add up to 3. Returning False at the first difference gives up too early, so [1, 2, 2, 2] fails. The last version looks at every window of three neighbours directly.

Python
def f(n):
    while n % 2 == 0 and n > 0:
        n = n // 2
    return n == 1

Choose one option

View answer and solution

Correct answer: B — It cannot be determined without more information about n

The loop divides out every factor of 2, and the result is 1 only if nothing else was left, so f(n) is True exactly when n is a power of 2. Being even is not enough: f(8) is True, but f(6) ends at 3 and is False.
