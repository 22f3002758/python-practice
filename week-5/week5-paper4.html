View answer and solution

Correct answer: A — 25 30 55

Question 4MCQ

Given the following code snippet, what will be the output?

Python
total = 10

def f(total):
    total = total + 5
    return total

def g():
    global total
    total = f(total) * 2
    return total

print(f(1), g(), total)

Choose one option

View answer and solution

Correct answer: A — 6 30 30

The parameter total in f is local and hides the global, so f(1) is 6. g passes the global 10 to f, gets 15 and stores 30 in the global total. The arguments of print are evaluated left to right, so total is read after g() has run.

Output
6 30 30

Question 13NAT

What number is printed by the following code?

Python
calls = 0

def binom(n, k):
    global calls
    calls += 1
    if k == 0 or k == n:
        return 1
    return binom(n - 1, k - 1) + binom(n - 1, k)

binom(4, 2)
print(calls)

Enter a number

View answer and solution

Correct answer: 11

Every call either is a base case returning 1 or makes two calls. binom(4, 2) is 6, which is a sum of 6 base cases, and those take 5 non-base calls to combine, so there are 6 + 5 = 11 calls.

Output
11

moves = []

def hanoi(n, src, via, dst):
    if n == 0:

hanoi(2, 'A', 'B', 'C')
print(moves)

Choose one option

View answer and solution

Correct answer: B — ['AB', 'AC', 'BC']

To move 2 discs from A to C, the top disc first goes from A to B (the inner call swaps via and dst), then the big disc goes from A to C, and then the small disc goes from B to C.
