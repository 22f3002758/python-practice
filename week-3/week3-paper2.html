Question 3MCQ
3 marks · no negative marks

Consider the below code. What is the output when the input is hi there 42u?

Python
s = input()
out = ''
upper = True
for ch in s:
    if ch.isalpha():
        if upper:
            out = out + ch.upper()
        else:
            out = out + ch.lower()
        upper = not upper
    else:
        out = out + ch
print(out)

Choose one option

View answer and solution

Correct answer: C — Hi ThErE 42u

upper flips only after a letter, so spaces and digits are copied unchanged and do not break the alternation. The letters get upper, lower, upper, ... in order: H i T h E r E u, so u (the eighth letter) is lowercase.

Hi ThErE 42u

Question 6MCQ
3 marks · no negative marks

A programmer wants to print the even numbers from 10 down to 2, one per line. Which statement does this?

Choose one option

View answer and solution

Correct answer: D — for k in range(10, 1, -2): print(k)

The stop value is excluded, so it must lie beyond 2 in the direction of travel: any stop of 1 or 0 works with step -2. A stop of 2 drops the last number. With a negative step the start must be larger than the stop, otherwise the range is empty, and a positive step from 10 towards 0 is empty too.

        break
    result = result + i

View answer and solution

Correct answer: A and C

Choose one option

View answer and solution

Correct answer: B — The number of moves after which the robot first returns to its starting point

step counts the moves made so far. The position is checked after every move, and break stops at the first time it is back at (0, 0), so only that step number is printed. If it never returns, nothing is printed.
