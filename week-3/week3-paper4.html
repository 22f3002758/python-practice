Question 8MCQ

Both snippets read an integer n (at least 2) and should print prime if it is prime and not prime otherwise. Choose the correct option.

Snippet-1

Snippet-1
n = int(input())
d = 2
while d < n:
    if n % d == 0:
        break
    d += 1
if d == n:
    print('prime')
else:
    print('not prime')

Snippet-2

Snippet-2
n = int(input())
prime = True
for d in range(2, n):
    if n % d == 0:
        prime = False
    else:
        prime = True
if prime:
    print('prime')
else:
    print('not prime')

Choose one option

View answer and solution

Correct answer: C � Only Snippet-1 is correct

Snippet-1 stops at the first divisor, so d reaches n only when there is none. Snippet-2 overwrites prime on every pass, so only the last divisor tested matters: for 9, 9 % 8 is not 0 and it prints prime.

        break
    total += i

Choose one or more options

View answer and solution

Correct answer: A, C and D

i runs from 1 to 6. The value equal to num is skipped and the loop breaks at num + 3. When neither happens (num <= -3 or num >= 7), the total is 21. num = -2 breaks at 1 (0), and num = 3 skips 3 and breaks at 6 (1 + 2 + 4 + 5 = 12). The possible totals are 0, 1, 3, 5, 8, 12, 15, 16, 17 and 21.
