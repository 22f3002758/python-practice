How many # characters does the following code print?

Choose one option

View answer and solution

Correct answer: D � 8

Question 8MCQ

Both snippets read a positive integer n and should print the largest power of 3 that is less than or equal to n (1, 3, 9, 27, ...). Choose the correct option.

Snippet-1

Snippet-1
n = int(input())
p = 1
while p * 3 <= n:
    p = p * 3
print(p)

Snippet-2

Snippet-2
n = int(input())
p = 1
while p <= n:
    p = p * 3
print(p // 3)

Choose one option

View answer and solution

Correct answer: B � Both snippets are correct

Snippet-1 multiplies only while the next power still fits, so p ends on the answer. Snippet-2 overshoots: it stops at the first power larger than n and then divides by 3 to step back one power. For n = 1, it goes from 1 to 3 and prints 3 // 3 = 1, so both are correct.
