Question 11MSQ

L is a list of integers. Select all statements that are true after r = tally(L) runs, for any such L.

Python
def tally(L):
    d = {}
    for x in L:
        if x > 0:
            d[x] = d.get(x, 0) + 1
    return d

Choose one or more options

View answer and solution

Correct answer: A and C

Only positive elements are counted, so every key is positive and the values add up to the number of positive elements, which is at most len(L). Zeros and negative numbers are left out, so the sum and the number of keys can both be smaller.

Questions 23 and 24 are based on the following function. A and B are any two sets of integers. What does f(A, B) return?

Python
def f(A, B):
    return len(A | B) == len(A) + len(B) - len(A & B)

Choose one option

View answer and solution

Correct answer: D — It is always True

Adding len(A) and len(B) counts each element of both sets twice; taking away len(A & B) once leaves each element counted once, which is len(A | B). So it is always True.
