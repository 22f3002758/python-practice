Question 8MCQ
3 marks · no negative marks

Both snippets define invert(d), which should return a new dictionary that maps each value of d to its key. Assume the values of d are all different. Choose the correct option.

Snippet-1

Snippet-1
def invert(d):
    r = {}
    for k in d:
        r[d[k]] = k
    return r

Snippet-2

Snippet-2
def invert(d):
    r = {}
    for v in d.values():
        for k in d:
            if d[k] == v:
                r[v] = k
    return r

Choose one option

View answer and solution

Correct answer: D — Both snippets are correct

Snippet-1 stores each key under its value directly. Snippet-2 takes each value and searches the keys for the one that holds it; it does more work, but since the values are all different it finds the right key every time.
