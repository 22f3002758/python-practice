Question 8MCQ
3 marks · no negative marks

Both snippets define same_letters(a, b), which should return True if the two strings use exactly the same letters, ignoring how many times each letter occurs (so 'aab' and 'ba' count as the same). Choose the correct option.

Snippet-1

Snippet-1
def same_letters(a, b):
    return sorted(a) == sorted(b)

Snippet-2

Snippet-2
def same_letters(a, b):
    for ch in a:
        if ch not in b:
            return False
    for ch in b:
        if ch not in a:
            return False
    return True

Choose one option

View answer and solution

Correct answer: C — Only Snippet-2 is correct

Snippet-1 compares the sorted letters, which also compares how many times each occurs, so 'aab' and 'ba' give False. Snippet-2 checks both directions: every letter of a is in b and every letter of b is in a, which is the same as set(a) == set(b).
